\definevalorquestao

\begin{exercicioBanco}[\valorquestao]
    O intervalo \([35,21; 35,99]\), com confiança de 95\% foi construído a partir de uma amostra de tamanho 100, para a média \(\mu\) de uma população Normal com desvio padrão igual a 2.
    \begin{enumerate}[(a)]
        \item Qual o valor encontrado para a média dessa amostra?
        %
        \item Se utilizássemos essa mesma amostra, mas com uma confiança de 90\%, qual seria o novo intervalo de confiança?
    \end{enumerate}
\end{exercicioBanco}
