\begin{exercicioBanco}[\valorquestao]
    Uma marca particular de margarina diet foi analisada para determinar o nível (em porcentagem) de ácidos graxos insaturados. Uma amostra de seis pacotes resultou nos seguintes resultados: 16,8; 17,2; 17,4; 16,9; 16,5; 17,1. Supondo distribuição normal para o nível de ácidos graxos insaturados:
    \begin{enumerate}[(a)]
        \item Teste a hipótese \(H_{0}: \mu = 17\) versus a hipótese \(H_{a}: \mu \neq 17\), usando \(\alpha = 0,01\).
        \item Determine o nível descritivo do teste, \(\alpha^{\ast}\).
    \end{enumerate}
\end{exercicioBanco}
