\begin{exercicioBanco}[\valorquestao]
    Uma urna contém 3 bolas numeradas: $1$, $2$ e $3$. A probabilidade de retirar cada bola é proporcional ao número escrito nela. Duas bolas são retiradas sucessivamente, com reposição. Se a soma dos números das bolas retiradas for:

\begin{itemize}
    \item $2$, o jogador ganha R\$80,00;
    \item $3$, o jogador ganha R\$50,00;
    \item $4$, o jogador ganha R\$20,00;
    \item Qualquer outro resultado, ele não ganha nada.
\end{itemize}

    Determine o ganho médio esperado do jogador.
\end{exercicioBanco}
